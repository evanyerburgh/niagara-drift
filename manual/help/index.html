Installing and updating

ToDo
InstallOpen the web installer in Chrome or Edge, with a USB data cable straight into the computer
UpdateRun the installer again. Your sounds and scenes are kept, unless that version's notes in the changelog say otherwise

Installing firmware is at your own risk.

An install doesn't take

Nothing is written until the FM-1 has checked the whole package, so trying again is safe. Work down the steps:

  1. Use a USB data cable straight into the computer, close other apps that use MIDI (a DAW, M-UPGRADE), replug, and try again.
  2. Going back from 0.2 or another firmware, and nothing was written: choose the other M-VAVE file (V16 or V15). Each takes back only the version whose bootloader the FM-1 has; from 0.2.1 on, Niagara Drift takes either.
  3. Still stuck: hold OCT− and OCT+ for 5 seconds. The FM-1 goes into its chip's own update mode, which no firmware can get in the way of, and M-Flasher (Windows, Mac, Linux) puts M-VAVE's firmware back. If an FM-1 won't start at all, see below.

Newer FM-1s on 0.2. Up to 0.2, Niagara Drift didn't recognize the memory chip of some newer FM-1s; there it couldn't save and ignored installs. On such an FM-1 running 0.2, use step 3 to leave it. Since 0.2.1 it takes any standard chip: the newer UC25HQ80 (ID B36014) and the first Puya P25Q80 (856014).

An FM-1 that won't start

The FM-1's chip has its own update mode that no firmware can overwrite, so an FM-1 that won't start can still be put back on M-VAVE's firmware from a computer, with a USB data cable straight in.

  1. Switch it off and on. After two failed starts in a row it comes up in safe mode (no sound, USB on): open the install page and install again, or put M-VAVE's firmware back.
  2. Nothing on the screen at all: switch it off and on a few more times. After four failed starts it opens the chip's update mode by itself.
  3. Download M-Flasher, a free app for Mac, Windows and Linux. It finds the FM-1 in its update mode: choose M-VAVE's FM-1 file and press REVIEW & FLASH. It saves the whole FM-1 to a file before it writes anything. The install page's "Trouble installing?" card shows each step.
  4. Switch the FM-1 off and on: it starts with M-VAVE's firmware, and the install page works again.

Good to know. A terminal on a Mac or Linux can do step 3 with tools/fm1_rescue.sh, a script that checks the chip and backs it up first (BUILDING.md).

Backups

WhenWhat happens
Before every install over Niagara DriftBoth installers save your sounds, scenes and settings to a file: the web installer into your downloads (and it offers to put them back), the terminal one into ~/niagara-drift-backups/
Any timeThe web installer's "Your sounds and scenes" card saves or restores one, as python3 tools/fm1_install.py --backup and --restore FILE do; each reads the other's files
Trying another firmwareBack up first, restore when you come back
Onto another FM-1A backup leaves out the knobs' calibration, which belongs to each FM-1, so it can go onto another

Restoring is safe

  1. The whole backup goes onto the FM-1 and is checked first, changing nothing. A damaged file is refused before anything is written.
  2. The FM-1 asks RESTORE FROM USB?: SEL puts it back; HOME keeps what it has, as does a minute without either.
  3. Your sounds and scenes change all together or not at all, even if the power goes off halfway: the next power-on finishes it.

Going back, or to another firmware

ToDo
M-VAVE's firmwareThe installer's "Back to M-VAVE's firmware" writes V16 or V15 back over the same cable; or use M-VAVE's updater, M-UPGRADE, from m-vave.com/download
Another firmwareMost expect M-VAVE's: go back first, then install them

Safe mode. If Niagara Drift fails to start twice in a row, it comes up with no sound and USB on, and the installer still works.
