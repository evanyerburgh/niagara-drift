## 0.3.1 (2026-11)

重いサウンドもなめらかに鳴り、ドローン Iだけを休ませられるようになり、マニュアルが日本語になりました。0.3からの
アップデートでサウンドとシーンはそのまま残り、0.3.1で保存したサウンドは0.3でも読み込めます。旧型のFM-1でテスト
しています。

- **重いサウンド：**Shimmer、Feedback、速いLFOを同時に使うと、ページのボタンが何度か押さないと効かないことや、
  変更のたびに音が数秒途切れることがありました。オーディオの処理が軽くなり（負荷が約14ポイント減少）、すべての
  タップが届くようになりました。
- **ドローン Iだけをオフに：**HOME + PLAYで、ドローン IがFade timeをかけてフェード・アウトし、また
  フェード・インします。ドローン IIのSEL + PLAYと対になる操作です。ヘッダーにI OUTと出ます。
- **SEL + ピッチのノブを速く回すとなめらかに移る：**ゆっくり回すと、これまでどおり1クリック1セント。速く回すと、
  音と音のあいだを自由にスイープします。
- **ディレイのTimeが曲がる：**速く回すと、短く明るい「ジッ」という音ではなく、テープのようにピッチが曲がります。
  シーンやプリセットでタイムが飛ぶときも、エコーがすっと移ります。
- **ヘッドホン：**ドローンを小さくしてTickを軽く押さえたとき、音が左右に振られなくなりました（出力の前で12 Hz以下を
  ゆるやかにカット）。
- **ジェスチャー・キー**は、ジェスチャーが聞こえている分だけ暗い状態から点灯し、パネルのライトはすべて段差なく
  フェードします。
- **画面：**Pitchページは2つのドローンの波形を1本の時間軸に描くので、純正な音程は止まって見え、デチューンは
  流れて見えます。Resoを回したりフィルターのキーをタップしたりすると、そのドローンのフィルター・カーブが絵いっぱいに
  広がります。Spaceのラベルが絵から離れ、runawayの余韻が細くなりました。Setup 1は最短の時間をジャンプとして表示し、
  ヘッダーはLOOPのあった場所に押さえているジェスチャーを表示します。
- **マニュアルが日本語に：**すべてのページ（AIで翻訳しました。より自然な表現があれば歓迎します）。英語版も
  ファームウェアと照らし合わせて丁寧に見直しました。

## 0.3 (2026-11)

すべてのページの新しい見た目、16種類の新しいプリセット、8つのジェスチャー、11種類のTuning。マニュアルはこのサイトの
ページになりました。0.2または0.2.1からのアップデートでサウンドとシーンはそのまま残ります。旧型のFM-1でテストして
います。0.2.1と同じく、新しいFM-1のメモリー・チップにも保存できます。

- **新しい見た目：**すべてのページを描き直しました。暗く光る画面で、上に音の絵、その下に回しているものを表示します。
  動いているものは値を表示し、LFOが設定を動かすと、その絵も動きます。キーとボタンは音名で枠に入れて示します。
  パネルのライトは画面に合わせて動きます。暗いのは常にオフで、停止中に動くのはPLAYだけです（呼吸するように
  明滅します）。
- **16種類のプリセット**を2つのバンクに。それぞれ別の雰囲気で、1分ほどのあいだに動いていきます：Niagara、Embers、
  Vespers、Dreamhouse、Abyss、Seance、Sonar、Sibyl、Howl、Cistern、Piston、Ashram、Telegraph、Tape、Falling、Bare。
  アップデート後、0.3に残らない0.2のプリセット（Eerie、Glass、Tanpura、Whistle、Cathedral、Metal）はバンク6に
  入ります。
- **8つのジェスチャー：**上のキーにWeight、Shift、Clean、Wash。キー9–12にTick、Chord、Snarl、Stutter（押す強さで
  深さが変わります）。タップすると入ったままになり、ジェスチャーが入った状態で保存したシーンは、そのジェスチャーごと
  戻ります。
- **11種類のTuning：**12平均律、四分音、19・31・53平均律、純正律、倍音列、La Monte Young、Lou Harrison、
  シュルティ、Partchの43音。ピッチのノブはTuningの音に止まり、画面はドローン間の音程をそのTuningの呼び方で表示します。
  Partner、Shift、Wander、ChordもTuningに従います。サウンドはTuningごと保存されます。Aは427〜453 Hzで調整できます。
- **番号で選ぶバンク：**自分用が6つ、プリセットが2つ。SELとジェスチャー・キーで選びます。自分のシーンは48個。
  シーンは3.5（バンク3、キー5）のように表示します。
- **新しい音：**Shimmerリバーブ（きらめくオクターブが1つ、満ちては引いていきます）。エコーが自分のタイムを動かす
  GrainディレイとSelfディレイ。ディレイの後のドライブ。ドローンどうしがピッチを曲げ合うクロス・モジュレーションと
  Snarl。歌うFeedback。ドローンごとのサブ・オシレーターの波形。ピッチは2 Hzまで、サブは4オクターブ下まで。
- **LFO：**ステップ状のANDとORの波形。いちばん遅いレートは100秒で1周。X-Waveとレゾナンスは端で折り返すので、
  スイープのどの部分も聞こえます。
- **MIDIクロック：**Swell、LFO、ディレイ、Wander、Scene timeがクロックに従います。Setup 1のSyncで、ドローンを
  クロックから外して自由に動かせます。
- **ページ：**HOMEはDrones（レベルとカットオフ）、FXはSpace（エフェクトの量）を開きます。Feedbackは
  LifeのKNOB 1、Cross-modはModsのKNOB 4、TuneはSetup 2のKNOB 2に移りました（一度だけヒントが出ます）。
- **モーション・ループ**は、ジェスチャーとシーンも記録します。
- **スクリーン・リーダー：**Charles VestalのFM-1 Screen Readerのために、画面を言葉で伝えます。
- **インストーラー**はインストールの前にサウンドとシーンを保存し、「サウンドとシーン」のカードで元に戻せます。途中で
  切れた復元は、次の起動時に最後まで行われます。
- **マニュアル**はこのサイトのページになりました：ここで弾く、レシピ、リファレンス、ショートカット、ヘルプ。
  アカウントなしでフィードバックも送れます。

## 0.2.1 (2026-11)

どのFM-1でも、Niagara Driftを入れたり外したりできるように。音は0.2と同じで、0.2からのアップデートでサウンドと
シーンはそのまま残ります。旧型のFM-1でテストしています。新しいFM-1のメモリー・チップはまだこちらで試していません。

- **新しいFM-1：**0.2は一部の新しいFM-1のメモリー・チップを認識できず、保存できないうえ、すべてのインストールを
  無視していました（起動し直すだけでした）。0.2.1は標準的なメモリー・チップならどれでも動き、インストールを無視
  しません。0.2のままのそういったFM-1は、一度[M-Flasher](https://github.com/jvitkauskas/m-flasher)を使って
  外す必要があります。インストール・ページの「インストールがうまくいかない？」に手順があります。
- **M-VAVEのV16またはV15に戻せる**ように。FM-1のブートローダーがどちらでも戻せます（0.2は、すでに持っている
  ブートローダーのバージョンにしか戻せず、V15のブートローダーのFM-1はV16を受け付けませんでした）。Charles Vestalの
  修正で、felucca-bspからのものです。
- **インストーラーがM-VAVEのV16**にも対応しました（M-VAVEのリンクは今はV16。V15はInternet Archiveにリンク
  しています）。0.2からは、「M-VAVEのファームウェアに戻す」がまずNiagara Driftを0.2.1にアップデートし、それから
  M-VAVEのファームウェアを書き込みます。ボタン1つです。
- **「インストールがうまくいかない？」**をインストール・ページとマニュアルに追加：インストールが通らないときに
  することです。

## 0.2 (2026-10)

より落ち着いて、より深い楽器に。初期設定はゆっくりした動き、弾くためのジェスチャーとプリセット、押す強さで
クロスフェードできるバンク単位のシーン。1台のFM-1でテストしています。0.1からのアップデートでサウンドとシーンは
そのまま残ります（シーン1–12はバンクA、13–16はB1–B4へ）。

- **新しい最初のサウンド**（プリセットP1、Niagara）：ゆっくり呼吸するような音。LFOがフィルターをスイープし、
  Swellがオン、ディレイとリバーブが入っています。
- **12種類のプリセット**（SEL + G5）、固定：Niagara、Abyss、Eerie、Glass、Heaven、Tanpura、Tape、Whistle、
  Howl、Cathedral、Metal、Clean。それぞれ音、動き、エフェクトが違い、音量をそろえてあります。Pitch lockがオンなら
  今のピッチを保ちます。新しいFM-1はこれらで始まります。
- **D5–G5のジェスチャー：**Weight（太く温かい低音）、Shift（両方のドローンが上下5度まで動く）、Clean
  （汚れを抜いて同じ音量に）、Wash（エフェクトの中へ）。長押し：押している間に入り、押していた時間と同じだけ
  ゆっくり抜けます。タップ：いっぱいまで入り、もう一度タップで抜けます。離すときにSELを押すと、その位置で
  止まります。PRESETSで**Gesture time**（x0.1–x10）を設定します。
- **バンク単位のシーン：**F3–C5に1バンク12個。バンクA、B、C、プリセット（SEL + D5..G5）。
  タップすると、Scene timeをかけてそこへ移ります。
- **押す強さでクロスフェード：**シーンのキーを押さえて強く押すほど、そのシーンへ深く入ります。離すと音は元へ
  なめらかに戻ります。いちばん強く押すとシーンに着地します（キーが点滅）。押さえたままSELを押すと、2つの
  あいだの混ざり具合で止まります。押す強さの感度はSetup 2にあります。クロスフェードはQuixotic7のアイデアで、
  キーの押す強さはVeloの検出をもとにしたMONK-1の方法（Charles Vestal）で読み取ります。
- **Pitch lock**（黒鍵4）、起動時はオン：ピッチのノブとシーンがピッチを変えません。
- **左のエンコーダーは常に有効：**SELECTがLFOのレート、ALGORITHMがMovement、PRESETSがGesture time。
  OCT− / OCT+でLFO Wave I / IIを選びます。ほとんどのページ・ボタンに2ページ（ボタンは最後に使ったページを
  開きます）。
- **新しい音と動き：**Age（テープ：暗く、ヒス・ノイズ、ワウとフラッター）、Wander（ドローン IIがスケール上で
  ゆっくりランダムなメロディーを奏でる）、Pitch glide、Shiftの動き、17種類のパートナーの音程（それぞれ平均律と
  純正律）、ノイズの色のブレンド。
- **新しいエフェクト：**ChoralRoot（Quixotic7）のものをもとに、新しく書き直しました。ステレオ・ディレイ（Tape、
  Wide、Ping-pong、Clean）と8ラインのリバーブ（Room、Hall、Cathedral、Chorus hall。長さはInfまで、フリーズ付き）。
  Feedbackはキーに合って鳴り、音量を保ちます。
- **スピーカーとヘッドホン：**FM-1がどちらを使っているかを検出します。スピーカーには低音のカット、ヘッドホンには
  全帯域。MASTERの上の5分の1は、同じ音量のまま出力を強くドライブします。
- **レベル**はオーディオ・カーブに（保存したサウンドの音量は変わらず、数値は高めに出ます）。バンドパスとハイパスは
  レゾナンスが高くても音量を保ちます。
- **画面**はサイトの色に：回しているものを大きく表示します。SELを押さえると黒鍵を鍵盤どおりに描き、触れると
  その名前を表示します。ライトは何段階かの明るさで点灯し、OCTのライトはLFOの波形に合わせて脈打ち、ARPはSwellに
  合わせて呼吸します。
- **ノブ**は、ゆっくり、止まりながら回しても、すべてのクリックを拾います。
- **保存とバックアップ：**最後の変更から4秒後に自動保存（最大で30秒に1回）。`fm1_install.py --backup`で
  サウンド、シーン、設定をファイルに保存し、`--restore FILE`で元に戻せます。ターミナルからNiagara Driftの上に
  インストールするときは、先に`~/niagara-drift-backups/`へバックアップを保存します（Webインストーラーはまだです）。
- **Webサイト：**エミュレーターのFM-1にすべての操作子の役割を表示し、マニュアルを出会う順（プリセット、
  ジェスチャー、シーンが先）に並べました。リンクのプレビューとアイコンも。

[ChoralRoot](https://github.com/Quixotic7/ChoralRootFM1)（Quixotic7）のエフェクトの設計、クロスフェードの
アイデア、インストール前のバックアップのアイデアに、そして[MONK-1](https://github.com/charlesvestal/fm1-monk)
（Charles Vestal）のキーの押す強さの読み取りに感謝します。

## 0.1 beta (2026-10)

最初の公開バージョン。1台のFM-1でテストしています。

- 2つのドローン。それぞれX-Wave（サイン波 → 三角波 → ノコギリ波 → 矩形波）、パルス幅、パートナー・オシレーター
  （音程、デチューン、平均律または純正律）、サブ（−1、−2オクターブ、⅓、⅕）、ホワイトまたはピンクのノイズ、
  12 dBのローパス、バンドパス、ハイパスのフィルターとドライブ。
- リンク：ピッチ・リンク、ハード・シンク、クロス・モジュレーション（ドローン Iがドローン IIのカットオフを動かす）。
- Ultra LFO：1つのレート（50秒で1周から70 Hzまで）、8種類の形から選ぶ2つの波形を、ピッチ / X-Waveと
  カットオフ / レゾナンスへ。レート・モジュレーション。Swellへのロック。Movement（OCT− / OCT+）で
  すべてのデプスを0–200 %に。
- Swell：両方のドローンがそろって呼吸し、スウィングも付けられます。
- エフェクト：PT2399風のディレイからリバーブ（Room、Plate、Hall、Chorus hall）へ。Feedback、Character、
  スピーカーの低音カット。
- Drift、Morph、白鍵に16個のシーン（今のシーンのキーが点滅）、5分のモーション・ループ。
- SAVEはすぐに書き込みます。演奏中でも保存でき（音が約50 ms小さくなります）、停止中は自動保存。
- 同じコードで動くブラウザーのエミュレーターと、M-VAVEのファームウェアにも戻せるWebインストーラー。

FoMniとX0X（Charles Vestal）、そしてFeluccaのFM-1プラットフォーム（Leo Kuroshita、Hügelton Instruments）の
上に作られています。FoMni自身のバージョンは、タグ`fomni-v0.1` … `fomni-v0.3.2`として残しています。
