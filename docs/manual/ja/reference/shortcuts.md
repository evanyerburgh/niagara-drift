## ショートカット {#shortcuts}

キーの組み合わせ、長押しとタップのすべてを1か所に。

## SELと組み合わせて {#with-sel}

### サウンドとシーン {#sounds-and-scenes}

| 操作 | 働き |
|---|---|
| [[SEL]] + [[PLAY]] | ドローン IIだけがフェード・アウト、またはフェード・インします |
| [[SEL]] + [[SAVE]] | 最後にシーンをタップした、または混ぜた前のサウンドに戻ります。もう一度で進みます。SAVEを離すまでSELを押したままにします |
| [[SEL]] + ジェスチャー・キー | シーンのキーが呼び出すバンクを選びます（[シーンのバンク](scenes.md#pick-a-bank)） |
| シーンのキーを押しながら[[SEL]]をタップ | 配合がそこにとどまります（「1.5 40% KEPT」） |
| ジェスチャーを押しながら[[SEL]]をタップ | その時点の深さでラッチされます |

### ノブ {#knobs}

| 操作 | 働き |
|---|---|
| [[SEL]]を押しながらノブ | 細かいステップ：ピッチのノブは1セントずつ（速く回すともっと大きく、すべるように）、カットオフとレゾナンスは0.1ずつ、Shift's moveは1セント |
| Sub · Driveで[[SEL]] + KNOB 1か3 | 各ドローンのサブの波形 |
| Detailsで[[SEL]] + KNOB 2 | ディレイのタイプ |
| Detailsで[[SEL]] + KNOB 4 | リバーブに入れるもの |

### キーとLFO {#keys-and-the-lfo}

| 操作 | 働き |
|---|---|
| [[SEL]]を押したまま | 画面に黒鍵のマップ、ジェスチャー・キーにバンクが点灯 |
| [[SEL]]を押しながら黒鍵に触れる | 画面にそのキーの名前と設定が出ます。切り替えはしません |
| [[SEL]] + [[OCT−]]か[[OCT+]] | そのLFOの前の波形 |

## 長押しとタップ {#holds-and-taps}

### シーンのキー {#scene-keys}

| 操作 | 働き |
|---|---|
| [[SAVE]]を押しながら白鍵をタップ | そのキーにサウンドを保存します（プリセットには保存できません） |
| 白鍵を強く押す | 押した分だけ、そのシーンへクロスフェード |
| 白鍵をいっぱいまで押して少し保つ | そのシーンに切り替わります：離してもそのまま |

### ジェスチャー・キー {#gesture-keys}

| 操作 | 働き |
|---|---|
| ジェスチャー・キーをタップ | ジェスチャーがいっぱいまで入り、ラッチされます。もう一度タップで去ります |

### ボタンとページ {#buttons-and-pages}

| 操作 | 働き |
|---|---|
| ページのボタンを押したまま | そのページをのぞく：ノブを回して離すと、元に戻ります |
| ページのボタンをもう一度タップ | 次のページ（「1/2」） |
| Swellページで[[ARP]]をタップ | Swellのオン・オフ |
| [[REC]]を3回タップ | 動きを記録、ループ、停止 |
| [[HOME]] + [[PLAY]] | ドローン Iだけがフェード・アウト、またはフェード・イン |

### 黒鍵 {#black-keys}

| 操作 | 働き |
|---|---|
| [[D#4]]を0.5秒長押し | LFOをSwellに同期（もう一度で解除） |

### インストールが止まったとき {#a-stuck-install}

| 操作 | 働き |
|---|---|
| [[OCT−]]と[[OCT+]]を5秒間長押し | チップ自身のアップデート・モード。インストールが止まったときに（[ヘルプ](../help.md)を見てください） |
