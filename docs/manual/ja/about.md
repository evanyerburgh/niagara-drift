呼吸し、漂う2つのドローンを、自分の手で弾きます。レベル、フィルター、ピッチを手で操り、そしてサウンド全体を一度に動かす
ジェスチャーとシーン。ヘッドホンで聴く旅を、ひとりで、またはほかの楽器と一緒に。Lyraの雰囲気を、FM-1のために。

グルーヴボックスではありません：鍵盤でメロディーは弾かず、シーケンサーもなく、自動で作曲もしません。

## 仕様 {#technical-details}

### サウンド {#sound}

| | |
|---|---|
| **オーディオ** | 44.1 kHzステレオ。内部は32ビット浮動小数点、出力は24ビット。5.8 msごとに1ブロック |
| **オシレーター** | バーチャル・アナログ。4つの波形（サイン波、三角波、ノコギリ波、矩形波）を連続的にブレンドし、パルス幅も可変。ノコギリ波とパルスは帯域制限（polyBLEP）。ハード・シンク、クロスFM |
| **パートナー** | 各ドローンの2つめのオシレーター：1オクターブ下、5度下か4度下、ユニゾン、3度・4度・5度上、1オクターブ上、1オクターブと5度上。それぞれ平均律か純正（うならない）。ゆっくりしたうなりのために最大30セントのデチューン |
| **サブとノイズ** | 4つの波形（矩形波、サイン波、三角波、ノコギリ波）のサブ。1–4オクターブ下、またはサブハーモニックの⅓と⅕。低いドローンの下では、いちばん低いものがクリックやパルスになります（[レシピ](recipes/sounds.md#ticks)）。ホワイトからピンクまでのノイズ |
| **フィルター** | ステート・バリアブル・フィルター（ゼロ・ディレイ・フィードバック、Andrew Simperにもとづく）：ローパス、バンドパス、ハイパス。自己発振するまでのレゾナンス。エイリアシングを抑えたドライブ |
| **エフェクト** | 70 msから1.45秒のディレイ（クリーンからテープまで6タイプ）。ディレイとリバーブの間にドライブ。8本のラインによるリバーブ（0.3から40秒またはフリーズ、5タイプ）。ドローンと共鳴する8本の弦（[SpaceとDetails](reference/space.md)） |

### 動きとチューニング {#movement-and-tuning}

| | |
|---|---|
| **LFO** | それぞれ10の波形を持つ2つの波（全20：三角波、矩形波、ノコギリ波、指数カーブ、パターン、ランダム、ANDとORのステップ）。100秒に1周期から70 Hzまで。ピッチ、波形、カットオフ、レゾナンス、ディレイへ |
| **チューニング** | Aを427から453 Hzまで（初期設定は440、好みの人には432も）。1クリック1 Hz、SELで0.1 Hz。12音、4分音、19・31・53音、純正律、倍音列、La Monte Young（LMY）、Lou Harrison、シュルティ、Harry Partch |
| **デチューン** | 各ドローンを、Tuningの音から1セントずつずらせます（SEL + ピッチのノブ）。音を移ってもそのまま保たれます。各パートナーは最大30セントでうなりを。Driftでデチューンをさまよわせます |

### 演奏と接続 {#playing-and-connecting}

| | |
|---|---|
| **ポリフォニック・アフタータッチ** | シーンのキーとキー9–12それぞれの押す強さを、押している間読み取ります。シーンはクロスフェードし、押す強さのジェスチャーがそれに従います。タッチは設定できます（Setup 2）。USBで送り出しもします（[MIDIイン](reference/midi.md#good-to-know)） |
| **MIDI** | USBとTRSでイン：チャンネル1と2のノートでドローンをチューニング。クロック（1拍24パルス）とスタート、Syncのオン・オフあり（[MIDIイン](reference/midi.md)） |

### 保存とライセンス {#storage-and-license}

| | |
|---|---|
| **保存** | 8シーン×6バンクと16種類のプリセットを、FM-1のフラッシュに。インストールのたびに、その前にファイルへバックアップ。途中で電源が切れても壊れない復元（[ヘルプ](help.md)） |
| **ライセンス** | GPL-3.0。ソースは[GitHub](https://github.com/evanyerburgh/niagara-drift)に |

## 成り立ち {#where-it-came-from}

名前は、『Day of Niagara』（the Theatre of Eternal Music、1965年）と、La Monte Youngの『Drift Studies』から。Stylophone CPM
DS-2、Moog Subharmonicon、Soma Lyra-8のアイデアから始まり、独自の楽器へと育ちました。
